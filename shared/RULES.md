# Build rules for every concept (art director's standing orders)

- One self-contained file: `homepage-concepts/<letter>.html`. Link `shared/fonts.css` (`<link rel="stylesheet" href="shared/fonts.css">`); all other CSS inline in a <style>. JS only where it earns its place (e.g. fitting stacked poster type). No frameworks, no external images — only `img/...`.
- Read `shared/CONTENT.md` first. Real stories, real bylines, real images only. No lorem ipsum, no invented stories. You may write short UI copy (CTA labels, section intros) in L.A. TACO's blunt, warm, local voice — plain verbs, sentence case.
- Desktop-first: design at 1440 wide (content grid 1320px, 60px side margins, 12 columns, 24px gutters — same as the client). Full-bleed elements must span the viewport. Must look intentional at 1280–1920. Provide a sane stacked fallback below 900px (not the focus, just not broken).
- Photos are the hero material: the client loves BIG photos. Use object-fit: cover with thoughtful object-position. Never tint food photography.
- Sutro is the headline voice. Set a deliberate type scale; tighten leading on big Sutro (0.95–1.05); letter-spacing around 0 to -0.01em at display sizes. Source Serif 4 for deks/body (line-height 1.45–1.55, measure < 70ch). Plex Sans for UI/meta.
- AVOID these generic tells: tracked ALL-CAPS eyebrow labels over every heading; meta joined with middle dots ("A · B · C"); "→" or "↗" appended to links; monospace labels; uniform rounded cards with soft grey shadows; gradient washes as decoration; fade-and-slide-up on every section; numbered 01/02/03 markers on things that aren't sequences (guide COUNTS like "19" are real info and fine).
- Motion: exactly ONE orchestrated moment (described in your brief), wrapped in `@media (prefers-reduced-motion: no-preference)`. Hover states may be subtle.
- Accessibility floor: semantic landmarks (header/nav/main/footer), real <a> links (href="#"), alt text on images, AA contrast for text, visible :focus-visible.
- Do NOT edit anything in shared/ or img/ or other concept files. Do not add a concept switcher (the art director adds it).
- VERIFY VISUALLY. The dev server is running at http://localhost:8765/homepage-concepts/<letter>.html. Other builders share the same browser pane, so FIRST call `mcp__Claude_Browser__tabs_create` to get your own tab, then pass that `tabId` on EVERY browser tool call (navigate, resize_window, computer screenshot, javascript_tool). Set your tab to 1440x900 with resize_window (width 1440, height 900, tabId). Screenshot each section (scroll with javascript `window.scrollTo`), critique hard (alignment, overlaps actually overlapping, type sizes, collisions, empty gaps, image crops), and fix. At least 2 full critique passes. Sutro renders only in this browser (it's a locally installed Adobe font) — if headlines look like Georgia, something is wrong with your font-family.
- When done, reply with: what you built section by section (short), the signature moves, and any known issues. Keep the report under 300 words.
